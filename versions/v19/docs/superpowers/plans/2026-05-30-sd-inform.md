# sd-inform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reusable `<sd-inform>` page-level banner/alert component (status icon + title + body, optional close Ã—, optional action link or projected action, optional line-clamp with show-more/less), supporting the 6 theme colors, plus its docs, full test coverage, and a showcase demo page.

**Architecture:** New standalone OnPush component at its own secondary entry point `@sdcorejs/angular/components/inform`. Signals-first (`input`/`output`/`computed`/`signal`/`viewChild`). Color system + per-color auto status-icon mirror `sd-badge`. Close is uncontrolled (internal `dismissed` signal hides host + emits). Line-clamp overflow is measured from a `viewChild` body element; toggle visibility is sticky once overflow is seen. A tiny `[sdInformAction]` marker directive lets consumers project a custom action that overrides `actionLabel`.

**Tech Stack:** Angular 19 (standalone, `input`/`output`/`computed`/`signal`/`viewChild`/`afterNextRender`/`effect`/`contentChild`), Angular Material `MatIconModule`, `Color`/`MaterialIconFontSet` from `@sdcorejs/angular/utilities/models`, `TranslatePipe` from `@sdcorejs/angular/i18n`, Karma/Jasmine (ChromeHeadless).

    if (this.warning()) return 'warning';
    if (this.error()) return 'error';

      'c-primary': c === 'primary',
      'c-secondary': c === 'secondary',
      'c-info': c === 'info',
      'c-success': c === 'success',
      'c-warning': c === 'warning',
      'c-error': c === 'error',

  });

    if (this.hideIcon()) return null;
    return this.icon() || SD_INFORM_DEFAULT_ICON[this.effectiveColor()];
  });

  fontSetClasses = computed(() => {
    const f = this.fontSet();
    return {
      'material-icons': f === 'material-icons',
      'material-icons-outlined': f === 'material-icons-outlined',
      'material-icons-round': f === 'material-icons-round',
      'material-icons-sharp': f === 'material-icons-sharp',

    if (!el || this.expanded() || !this.lineClamp()) return;
