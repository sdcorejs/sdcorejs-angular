# `<sd-tree>` - 2026-06-10 11:15

## What was requested

Build a standalone `sd-tree` component for `sd-angular`, based on the existing tree behavior in `sd-table`, with static/lazy modes, lazy loading state, custom `childrenKey`, default folder icons, multi-selection, row commands, two-line ellipsis, leaf icon override, select/expand/collapse events, `sdTreeItemDef`, and accent-insensitive Vietnamese filtering.

## What was changed

- Added secondary entry point `projects/sdcorejs-angular/components/tree`.
- Added `SdTree`, `SdTreeItemDefDirective`, `SdTreeOption`, `SdTreeCommand`, `SdTreeNode`, and event/context models.
- Exported `@sdcorejs/angular/components/tree` from the components barrel.
- Implemented static tree mode with `childrenKey`, `defaultExpanded`, `maxDepth`, and indentation.
- Implemented lazy tree mode with `hasChildren`, `onExpandChildren`, loading spinner, and cached children written to `item.children`.
- Implemented multi-select checkbox and `selectedItemsChange` / `selectChange`.
- Refined selection to match `sd-table`: checkbox appears only when `selector.visible === true`; selected rows open a quick-action bar with `selector.actions`.
- Implemented row command menu with `more_vert`, hidden/disabled command resolution, and trailing layout.
- Implemented default branch icons (`folder_open` / `folder`) and optional leaf icon resolver.
- Implemented two-line clamped item content so long labels do not overlap commands.
- Refined row alignment/styling: smaller table-like checkbox, primary selected checkbox color, gray chevron, primary item icon, and custom templates can grow row height.
- Implemented public `filter(searchText)` with Vietnamese accent-insensitive normalization and ancestor retention for matching descendants.
- Added focused unit/component tests covering static, lazy, selection, commands, custom template, icons, filter, and layout constraints.
- Added `projects/sdcorejs-angular/components/tree/sd-tree.md`.
- Added `.sdcorejs/user-guide/components/tree.md`.
- Added showcase page `/components/tree`, route, and sidebar nav item.
