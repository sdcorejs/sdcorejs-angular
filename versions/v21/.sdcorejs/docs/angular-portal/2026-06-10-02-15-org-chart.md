## Decisions made

- Public data shape is a simple tree: `SdOrgChartItem { id; image?; title; description?; color?; expanded?; children? }`.
- `color` maps to CSS variable `--sd-org-node-color`; missing color uses a white card.
- Projected `sdOrgChartItemDef` has priority over `[itemTemplate]`, matching the "local projection wins" feel of `sd-table`.
- Collapse state is internal and keyed by stable `id`; `expanded` only seeds the initial/default state.
- `autoId` follows component conventions: host = `components-org-chart-<autoId>`, child parts = `<host>-<part>-<sanitized item.id>`.
- No pan/zoom, drag-drop, selection, or multi-parent graph support in this round.
