# Chuẩn bị release 2.7

Yêu cầu: lấy `main` mới nhất và chuẩn bị bump `2.7` cho `@sdcorejs/angular`.
Nhánh `chore/prepare-v2.7` bắt đầu từ
`3e3b27989f899713285757013fd0d8c7c7ff5aca` (PR #49 đã merge).
Các version mục tiêu: `19.2.7`, `20.2.7`, `21.2.7`, `22.2.7`; tag dự kiến `v2.7`.

Đã cập nhật manifest canonical v19 và sinh ba dòng còn lại bằng script sync.
Bốn manifest chỉ đổi version; dependency, peer, engine và lockfile giữ nguyên.

Không sửa source component/form/service hoặc archive đã phát hành.

## Nội dung release

Changelog gồm quick search và external filter/command UI của table, icon trạng
thái tròn, Sidebar V1, read-state panel hẹp, Confirm radio, badge và selection.
Sidebar refresh cùng bốn mục sửa UI được chuyển từ 2.6 sang 2.7 vì chúng được
merge sau tag `v2.6`; đối chiếu tarball npm xác nhận package 2.6 chưa chứa các
thay đổi này. Giữ các ghi chú recovery đã áp dụng cho transaction 2.6 và giữ
nguyên các archive/snapshot cũ.

Script `deploy.ps1` trước đó luôn ghi baseline Angular 21 cho Angular 22.
Đã tái hiện metadata sai với `22.2.7`, giới hạn fallback ở bản khởi đầu
`22.2.5`, rồi chạy chính biểu thức trong script cho 12 tổ hợp Angular major
19–22 và suffix 2.5/2.6/2.7: tất cả cho baseline đúng.

Snapshot `scripts/release-contracts/2.7.json` ghi fingerprint của npm baseline
`*.2.6` và bốn candidate build local. Export map giữ nguyên, không xóa packed
file, declaration hoặc authored source. API mới của table là tùy chọn; i18n
thêm thông điệp quick search và clear search. Đã đọc declaration diff và xác
minh riêng integrity, manifest, public surface cùng strict consumer compilation.
