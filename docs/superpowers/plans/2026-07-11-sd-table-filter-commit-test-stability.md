# SdTable Filter Commit Test Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the `onFilterCommit()` regression test deterministic on Angular 19, 20, and 21 without changing production behavior.

**Architecture:** Treat `setupTable()` as a loaded-fixture helper instead of returning while Angular effects and the initial debounced reload are still pending. Apply the test-only change to v19, then use the repository rollout script to keep v20 and v21 identical.

**Tech Stack:** Angular TestBed, Jasmine, Karma, `fakeAsync`, Angular signals/effects, RxJS debounce timers, PowerShell rollout scripts.

- [ ] **Step 2: Make `setupTable()` settle the initial Angular lifecycle**

In the v19 source spec, replace the helper with:

```typescript
function setupTable() {
  fixture = TestBed.createComponent(HostComponent);
  host = fixture.componentInstance;
  fixture.detectChanges();
  table = fixture.debugElement.query(By.directive(SdTable)).componentInstance as SdTable<Row>;

  // Angular 20+ may schedule another effect/change-detection turn before the
  // configuration promise can enqueue the initial 200ms debounced reload.
  tick();
  flush();
  fixture.detectChanges();
  tick(800);
  flush();
  fixture.detectChanges();
}
```

Remove the immediately repeated initialization blocks from each test that calls `setupTable()`:

```typescript
tick();
flush();
```

Keep each test's later `tick(600)` or `tick(800)` because those advances verify the behavior triggered by the operation under test.
